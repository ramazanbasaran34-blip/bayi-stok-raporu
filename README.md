# Bayi Model Stok Raporu

Bajaj ve Kanuni için bayi bazında hangi modelin hem bayi depoda hem konsinyede olmadığını gösterir.

| Link | Dosya | Amaç |
|---|---|---|
| `https://KULLANICI.github.io/DEPO/` | `index.html` | Yayın (herkesin gördüğü sürüm) |
| `https://KULLANICI.github.io/DEPO/preview/` | `preview/index.html` | Önizleme (denenen sürüm) |

## Güncelleme düzeni
1. Yeni sürümü önce `preview/index.html` olarak yükleyin, önizleme linkinden kontrol edin.
2. Doğruysa aynı dosyanın içeriğini `index.html` üzerine yükleyin. Yayın linki güncellenir.

## Not
Pasif bayiler `index.html` içindeki `PASSIVE` listesinden, gösterilmeyen modeller `EXCLUDED` listesinden yönetilir.
